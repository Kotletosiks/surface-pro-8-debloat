# Surface Pro 8 Debloat

Набор скриптов для чистки Windows 11 на Surface Pro 8 от фоновых процессов, телеметрии и предустановленных приложений.

Отличие от большинства «дебло‑скриптов»: **каждое изменение записывается с исходным значением**, откат делается одной командой, а службы, нужные именно Surface — LTE‑модем, перо, сенсорная клавиатура, звук — внесены в список неприкосновенных и не трогаются никогда.

## Требования

- Windows 11 (проверено на 25H2, build 26200)
- Windows PowerShell 5.1 — входит в систему, ставить ничего не нужно
- Права администратора

## Как пользоваться

Скачай репозиторий, распакуй, заходи в папку `scripts` и запускай файлы `.bat` двойным кликом. Права администратора запрашиваются сами.

Каждый запуск пишет два лога в `C:\Debloat\logs`: подробный лог действий и копию всего, что было видно в окне консоли.

### Порядок

```
run_all.bat      ← первая волна: снимок, точка восстановления, телеметрия,
                   фоновые службы, реклама, индексатор, OneDrive, виджеты
   перезагрузка
06_diag.bat      ← диагностика: смотришь, что осталось
run_all2.bat     ← вторая волна: приложения Store, автозагрузка, Edge, Copilot, службы
   перезагрузка
11_cleanup.bat   ← Copilot как обычная программа, временные файлы
10_fastboot.bat  ← по желанию: гибернация и быстрый запуск
```

### Все скрипты

| `01_restore_point.bat` | Точка восстановления Windows |
| `02_telemetry.bat` | Телеметрия: политики реестра, службы `DiagTrack`, `WerSvc`, `dmwappushservice`, задачи CEIP и Feedback |

| `04_ads_background.bat` | Реклама и «рекомендации» в Пуске, рекламный ID, фоновая работа приложений |
| `05_extras.bat` | Индексатор поиска, OneDrive, виджеты, облачные подсказки в поиске |
| `06_diag.bat` | **Только чтение.** Полный отчёт: автозагрузка явная и скрытая, все службы с описаниями, приложения Store и Win32, задачи планировщика, ошибки в журнале, время загрузки |
| `07_apps.bat` | Удаляет 23 приложения Store у пользователя и из образа |
| `08_startup.bat` | Автозагрузка, скрытые StartupTask, рекламные задачи, фоновый режим Edge, политики против Copilot и Game Bar |

| `10_fastboot.bat` | Включает гибернацию и быстрый запуск, ограничивает размер файла 40 % памяти |
| `11_cleanup.bat` | Удаляет Copilot, установленный как обычная программа, чистит временные файлы |

| `99_undo.bat` | Откат первой волны |
| `98_undo2.bat` | Откат второй волны |

## Что удаляет `07_apps.bat`

TikTok, SketchCreator, Clipchamp, Bing News, Bing Search, Copilot, Xbox Gaming App, Journal, Outlook (новый), Power Automate, To Do, Dev Home, Teams, Quick Assist, виджеты (`WebExperience`), CrossDevice, Start Experiences, старый Paint, остатки OneDrive, Dolby Access, Narrator QuickStart, Compatibility Enhancements.

Удаление идёт и у текущего пользователя, и из образа системы — иначе приложения возвращаются после крупного обновления Windows.

Два пакета Windows удалять не даёт, это нормально и ни на что не влияет: `Microsoft.XboxGameCallableUI` и `Microsoft.Windows.NarratorQuickStart`.

## Что не трогается никогда

Эти службы внесены в скрипт как неприкосновенные, потому что от них зависит работа именно Surface:

- `WwanSvc`, `SmsRouter`, `RmSvc`, `WUService` — LTE‑модем Quectel
- `SCardSvr`, `ScDeviceEnum`, `SCPolicySvc` — через подсистему смарт‑карт работает слот SIM
- `SurfaceService` — интеграция с прошивкой Surface
- `PenService`, `TabletInputService` — перо и сенсорная клавиатура
- `RtkAudioUniversalService`, `IntelAudioService`, `DolbyDAXAPI`, `cplspcon` — звук и графика
- `WinDefend`, `MDCoreSvc`, `WdNisSvc`, `mpssvc` — Defender и брандмауэр
- `wuauserv`, `BITS`, `Winmgmt`, `WpnService` — обновления, фоновая передача, WMI, уведомления

## Откат

Оригинальное значение каждого изменения пишется в `C:\Debloat\state\undo.tsv` и `undo2.tsv`. Формат — одна строка на изменение: тип, цель, исходное значение.

- `99_undo.bat` откатывает первую волну
- `98_undo2.bat` откатывает вторую

Откат идёт в обратном порядке. Реестр и службы возвращаются точно; **приложения Store восстанавливаются только если Windows ещё не стёрла их файлы** — иначе ставь из Microsoft Store, это одна кнопка. Copilot, удалённый как программа, возвращается только установкой с сайта Microsoft.

Плюс к этому `01_restore_point.bat` создаёт обычную точку восстановления Windows перед началом.

## Побочные эффекты, о которых стоит знать заранее

- **Индексатор поиска отключён** (`05_extras.bat`). Поиск в Пуске перестанет находить файлы и содержимое документов, останется поиск приложений и настроек. Если нужен — не запускай этот шаг или верни службу `WSearch` в `delayed-auto`.
- **`LanmanServer` отключена** (`09_services2.bat`). Папки этого компьютера перестанут раздаваться по локальной сети. Побочно перестаёт работать команда `net session` — поэтому проверка прав администратора во всех `.bat` сделана через `fltmc`, а не через неё.
- **`CDPSvc` отключена.** Перестаёт работать связь с телефоном и передача «Поблизости».
- **OneDrive удаляется**, но папка `C:\Users\<имя>\OneDrive` и файлы в ней не трогаются.
- **Быстрый запуск** (`10_fastboot.bat`) означает, что «Завершение работы» перестаёт быть полным выключением. Иногда это мешает при обновлении драйверов — тогда перезагружай, а не выключай.

## Устройство скриптов

Вся логика в трёх файлах PowerShell, `.bat` — только запускалки: поднимают права, вызывают нужный шаг и пишут консольный лог.

- `debloat.ps1` — первая волна, шаги `snapshot`, `restorepoint`, `telemetry`, `services`, `ads`, `extras`, `undo`, `all`
- `debloat2.ps1` — вторая волна, шаги `apps`, `startup`, `services2`, `fastboot`, `cleanup`, `simfix`, `undo`, `all`
- `diag.ps1` — диагностика, ничего не меняет

Файлы `.ps1` сохранены в UTF‑8 с BOM и переносами CRLF. Это обязательно: Windows PowerShell 5.1 без BOM читает файл как однобайтовую кодировку и ломается на кириллице.
